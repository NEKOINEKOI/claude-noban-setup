# Codex 搭建指令（可直接复制）

把下面整段发给 Codex，让它通过 SSH 连上服务器后落实。

## 主指令

```text
帮我搭建一个固定出口的 Claude 使用环境。

服务器上所有业务联网，包括 Claude Code、浏览器和后台程序，都必须走指定的静态住宅 IP。
住宅代理断开、超时或者重启时，宁可断网，也不能切回服务器原始 IP。
保留必要的 SSH 管理通道，并验证保护规则在服务器重启后仍然有效。

我的住宅代理信息：[填协议 / 地址 / 端口 / 账号 / 密码]
服务器 SSH：[填连接信息]

完成后逐条报告校验结果：
1. Claude Code、浏览器及后台程序是否统一走住宅代理，不退回原始 IP。
2. 代理断开 / 超时 / 重启时，业务是否断网而非回退。
3. DNS 是否已接管，IPv6 和其他 UDP 直连是否已阻断。
4. 整机重启后保护策略是否依旧生效，SSH 管理通道是否保留。
5. 断开代理，确认业务真的断了。
```

## 登录阶段追加

```text
继续：给服务器安装远程桌面和 Chrome，并通过 SSH 隧道连接远程桌面。
我要在服务器内的 Chrome 完成 Claude 登录和 Claude Code 授权。
关联邮箱也要在服务器浏览器里登录，收邮件和点登录链接都在这个环境完成。
```

## 多账号追加（有多个号时）

```text
继续：登录多个账号需要独立的 Chrome 用户配置文件。
给 A 账号和 B 账号各建一套 Chrome 用户配置，生成对应的桌面快捷方式，避免 Cookie 和会话混淆。
再用 tmux 配置 claude-a / claude-b 切换入口：
账号凭证各自独立保存，项目代码、CLAUDE.md、任务进度、交接记录共享同一份。
注意禁止多个会话同时修改同一份代码。
```
