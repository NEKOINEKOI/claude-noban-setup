# 给 agent 的讲解提示词示例

> 主人问"这是怎么做的"时，可以把下面这些当成示范。agent 应该照这个风格讲：大白话、有链路、有风险、不堆术语。

## 人话版（问"啥意思"时用）

```text
用大白话给我讲讲这个仓库的方案到底是怎么回事。
我不需要术语，你就告诉我：它解决什么问题、怎么解决的、为什么这么搞。
讲完告诉我风险在哪。
```

期望 agent 这样答：封号是因为环境老变、IP 是机房的、登录请求从本地发出。这套办法就是把 Claude 的登录和使用全搬到一台美国服务器上，配一个固定的美国住宅 IP，本地只远程操作。最关键的是代理断了宁可上网断了也不换回原来的 IP。不能保证不封号。

## 链路版（问"整个流程"时用）

```text
画一下这套方案的链路，从我的电脑一直到 Claude，标出每一步干什么、
为什么要走美国服务器和住宅 IP。
```

期望 agent 给出：`本地电脑 → 美国 AWS 服务器 → 美国静态住宅 IP → Claude`，并说明每一步的作用。

## 深挖版（问"为什么这么选"时用）

```text
为什么非要美国的亚马逊云 + 住宅 IP？用别的云行不行？
只换 IP 不行吗？代理断了会怎样？
```

期望 agent 从"环境一致性"讲：只换 IP 不够（登录、浏览器还在本地），只上服务器不够（机房 IP 一眼识别），不做断网保护等于没做（代理一挂就切回机房 IP）。AWS 那段合作背景要讲，但"白名单"是作者猜想必须点明。

## 成本版

```text
这套东西一个月大概多少钱？都有哪几笔？有没有隐藏成本？
```

期望 agent 读 [`docs/07-成本估算.md`](../docs/07-成本估算.md)，给出单账号约 ¥314–364/月、3 账号约 ¥597–647/月，并列出成品号连坐、Windows 授权、6 个月后抵扣到期等隐藏成本。

## 判断版（主人有真实场景时）

```text
我在的地方能用官方 Claude，还有必要折腾这套吗？
```

期望 agent 如实说：能走官方就别折腾，官方订阅和 API 的合规风险和折腾成本都低得多；这套主要给"当地用不了、又确实需要"的场景。

## 给 agent 的自我约束

无论主人怎么问，agent 都要守住 [`../AGENTS.md`](../AGENTS.md) 的红线：不承诺不封号、不代买成品号/住宅 IP、成品号风险必须提示、多账号 Cookie 隔离不等于独立出口、不编造原文没有的细节。
