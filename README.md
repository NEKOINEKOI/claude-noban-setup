# Claude 防封号：亚马逊云 + 固定住宅 IP 方案

> 一套让 Claude 登录、授权、日常使用全部运行在"固定美国出口"上的操作方式。
> 本地电脑只负责远程操作。作者实测：同一台服务器 + 同一个静态住宅 IP，跑 3 个 Pro 账号数月未封。

本仓库把一份飞书流传文档整理成 **agent 可直接消费的项目**：

- **给 agent 看**：仓库根目录的 [`AGENTS.md`](AGENTS.md) 定义了两种工作模式（执行 / 讲解）、红线和操作流程。agent 进入仓库即知道该怎么帮主人把事办了、该怎么讲明白。
- **给人看**：本 README 给全局概览，[`docs/`](docs/) 按步骤拆解，[`prompts/`](prompts/) 提供可复制的指令，[`source/`](source/) 存原文校对版。

> 重要：本方案**不保证不封号**，只是一套有限条件下的实测思路。请务必先读 [`docs/08-风险与免责.md`](docs/08-风险与免责.md)。

## 一句话讲明白

把 Claude 的**登录、授权、日常使用**全部搬到美国的亚马逊云服务器上，再给它配一个**固定的美国住宅 IP**；本地电脑只负责远程操作。

链路：

```text
本地电脑 → 美国 AWS 服务器 → 美国静态住宅 IP → Claude
```

类比：相当于在美国放了一台专门用 Claude 的电脑，你坐在自己电脑前操作它。

**整套方案最核心的一条**：宁可断网，也绝不换出口。住宅代理一断，业务立刻断网，绝不回退到服务器原始 IP。绝大多数"封号"就是出口在代理挂掉那一刻偷偷切回机房 IP 导致的。

---

## 为什么选亚马逊云（AWS）

1. 亚马逊与 Anthropic 有官方合作，AWS 通过 Amazon Bedrock 提供官方 Claude 模型 API，有公开资料可查。
2. 作者实测：同样思路在其他厂商服务器上，第一天正常、第二天封号；换到 AWS 后多个账号持续正常。
3. 作者猜测 AWS 或许在某类白名单内——**这是个人猜想，无确切信息源**，不要当成事实。

## 直接看结论：成本

| 项目 | 月费（USD） | 月费（CNY 约） |
|---|---|---|
| AWS EC2 t3.small（2C2G，美东） | $15.18 | ¥108 |
| EBS 30GB gp3 存储 | $2.40 | ¥17 |
| AWS 公网 IPv4 保留 | $3.65 | ¥26 |
| 美国静态住宅 IP（独享） | $3–10 | ¥21–71 |
| Claude Pro 订阅（月付） | $20 | ¥142 |
| Codex（复用已有订阅则边际成本 0） | $0 起 | ¥0 起 |
| **单账号起步合计** | **约 $44–51** | **约 ¥314–364** |

3 个 Pro 账号共用同一台服务器和同一个出口，只多付订阅费：约 **$84–91/月（¥597–647）**。

按 1 USD ≈ 7.1 CNY 粗算，以实时汇率为准。详细拆分和隐藏成本见 [`docs/07-成本估算.md`](docs/07-成本估算.md)。
