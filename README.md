## 方法概况

把 Claude 的登录、授权、日常使用全部放到一台美国 AWS 服务器上，配一个固定的美国住宅 IP。本地电脑只负责远程操作。

链路：

```text
本地电脑 → 美国 AWS 服务器 → 美国静态住宅 IP → Claude
```

最容易翻车的一条：代理断开、超时或重启时，要断网，不能切回服务器原始 IP。出口一变，前面的功夫就白费。
