# Claude 防封号：AWS + 固定住宅 IP

一套把 Claude 的登录、授权、日常使用全部搬到美国 AWS 服务器、配一个固定美国住宅 IP 的操作方法。本地电脑只负责远程操作，用来在直连不便的环境下稳定使用 Claude。

这个仓库主要给 agent 看。人不用逐篇读这些文档——想知道怎么做，直接问 agent，让 agent 讲；想动手搭，直接让 agent 照着做。根目录的 `AGENTS.md` 是写给 agent 的，它读完就知道怎么讲、怎么做，以及哪些话不能说。

## 方法概况

把 Claude 的登录、授权、日常使用放到美国服务器上，给它一个固定的住宅网络出口，本地只远程操作。

链路：

```text
本地电脑 → 美国 AWS 服务器 → 美国静态住宅 IP → Claude
```

最容易翻车的一条：代理断开、超时或重启时，要断网，不能切回服务器原始 IP。出口一变，前面的功夫就白费。
