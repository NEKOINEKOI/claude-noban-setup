# 07 — 成本估算

查证时间 2026-11-23。价格会变，下单前以各官网结算页为准。汇率按 1 USD ≈ 7.1 CNY 粗算。

| 项目 | 规格 | 月费 USD | 月费 CNY 约 | 说明 |

| AWS EC2 实例 | t3.small 2C2G，美东，Linux 按需 | $15.18 | ¥108 | t3.micro 1G 约 $7.59，跑远程桌面+Chrome 偏紧 |
| EBS 存储 | gp3 30GB × $0.08/GB | $2.40 | ¥17 | 系统 + 浏览器 + 项目文件 |

| Claude Pro | 月付 $20，年付折合 $17/月 | $20 | ¥142 | 含 Claude Code |
| Codex | 复用已有订阅则 0 | $0 起 | ¥0 起 | 只用来搭环境 |
| 流量 | 出方向每月前 100GB 免费 | ~$0 | ~¥0 | 文本流量很小 |
| **合计** | | **约 $44–51** | **约 ¥314–364** | |

三个 Pro 账号共用服务器和出口，只多付订阅费：约 $84–91/月（¥597–647）。换 Max（$100/月起）另算，先观察一个月用量再决定。

## 前期和隐藏成本

| 项目 | 费用 | 说明 |
|---|---|---|
| AWS 注册 | 0 起 | 新账号抵扣 $100 起，完成引导任务可到 $200，用 6 个月 |
| 住宅 IP 试用 | $1–4 | 先短买测纯净度再包月，别一上来包年 |
| Claude 成品号 | 不透明 | 渠道价格因来源而异，这里不提供报价；有被找回、违反条款的风险 |
| 搭建调试 | 时间 | fail-closed 出口 + DNS 接管要调，不是点几下就好 |
| Windows 授权 | +$7/月起 | Windows 实例比 Linux 贵，Linux + 远程桌面可省 |
| IP 连坐 | 无价 | 买到被封过的住宅 IP，新号直接跟着死，前面投入白费 |
| 代理断网 | — | 保护生效时代理一挂就上不了 Claude，直到恢复，这是设计如此 |
| 抵扣到期 | — | AWS 抵扣只管 6 个月，之后全额计费 |

## 价格来源

- EC2 按需价：AWS 官方 EC2 定价页及第三方价格库（us-east-1、Linux、730 小时/月，2026-09 更新）。
- EBS gp3 $0.08/GB-月、公网 IPv4 $0.005/小时、出方向前 100GB 免费：AWS Price List（us-east-1，2026-09-18）。
- 美国独享静态住宅 IP $3–10/月：2026 年主流代理服务商公开行情区间。
- Claude Pro $20/月（年付 $17/月）、Max $100/月起：Anthropic 官方定价页。
