## 3 个 Pro 账号

共用同一台服务器 + 同一个住宅出口，只多付订阅费：

- $44–51 + $20×2 = **约 $84–91/月（¥597–647）**
- 换 Max（从 $100/月起）另算，原文建议先观察一个月用量再决定。

## 隐藏成本 / 容易忽略的账

1. **Windows 授权**：如果要开远程桌面的 Windows 实例，比 Linux 贵一截（t3.small Windows 约 $22/月起）。原文没指定系统，Linux + 远程桌面方案可省这笔。
2. **成品号连坐**：买到被封过的住宅 IP，新号直接跟着死，前面投入打水漂——这是最大的隐性风险成本。
3. **6 个月后抵扣到期**：AWS 新账号抵扣只管 6 个月，之后按上表全额计费。
4. **代理断网的代价**：断网保护生效意味着代理一挂就上不了 Claude，直到恢复。这是设计如此，不是故障。
5. **多账号不等于省事**：号越多，交接文件管理越复杂，同时改代码的冲突风险越高。

## 和替代方案的粗略对比

| 方案 | 月成本约 | 稳定性 | 合规风险 |
|---|---|---|---|
| 本站方案（AWS + 住宅 IP + Pro） | ¥314–364/号 | 作者实测数月稳定 | 中（成品号、规避条款） |
| 官方 Claude Pro 直接订阅 | ¥142–145 | 官方 | 低 |
| Claude API 按量付费 | 看用量 | 官方 | 低 |
| Amazon Bedrock 官方 Claude API | 看用量 | 官方、有 AWS 合作 | 低 |

> 如果所在地能正常访问官方渠道，后两者的合规风险和折腾成本都远低于本方案。本方案更适合"当地用不了、又确实需要稳定使用"的场景。
