# 02 — 准备工作

四样东西，缺哪样先补哪样。

## 1. 一台美区 AWS 服务器

- 区域选美国。西部（如 us-west）或东部（us-east-1）都行，东部更便宜，价格数据多基于东部。
- 起步配置 t3.small（2 vCPU / 2 GiB）够用；t3.micro（1 GiB）便宜，但跑远程桌面 + Chrome 会紧。
- 新账号有抵扣额度（$100 起，完成引导任务可到 $200，用 6 个月），注意不是过去那种免费一年。

## 2. 一个美国静态住宅 IP

关键区分：要的是住宅代理的固定出口，**不是** AWS 控制台里的静态公网 IP。后者是机房 IP，正是要避开的。

- 尽量和服务器在同一区域，先把链路跑稳。
- 优先选独享，共享 IP 会被别人的操作连累。
- 拿到后自己验证：用 IP 查询工具看归属地是不是美国、运营商是不是当地宽带运营商（如 AT&T / Comcast），不是机房 ASN。

### 选购避坑

| 坑 | 说明 |
|---|---|
| 买到被封过的 IP | 新号会被连坐。这是买住宅 IP 最大的运气成分。 |
| 假的住宅 IP | 价格明显低于区间的多半有问题，拿到手必须验证。 |
| 共享当独享卖 | 独享 $3–10/月是正常区间，$1 上下的多半是共享。 |
| 不先测试就包月 | 靠谱商家支持试用或短买，先确认能用、延迟能接受再包月。 |
| 流量和并发没问清 | 便宜套餐算上流量费可能更贵，问清上限。 |

参考价：独享静态住宅 IP 约 $3–10/月，指定城市或运营商上浮 20%–50%。详见 `07-成本估算.md`。

## 3. 一个能用的 Codex

作用：通过 SSH 搭环境、检查代理、验证断网保护。说清要求，它负责落实配置。指令模板在 `prompts/`。复用已有订阅则边际成本为 0。

## 4. Claude Pro 账号

充值 Pro 需要完成 KYC。成品号渠道来源不明，可能违反服务条款、可能被找回，风险自己评估。

起步策略：先一个号，观察一个月；有实际需要再加；稳定后再考虑 Max。用满一个月不代表后面一定安全。号不够用多个 Pro，不必急开 Max，记忆可以共享，换号不麻烦。

## 开局顺序

1. 短买一个住宅 IP，测纯净度和归属。
2. IP 干净后再开 AWS 服务器，同区域。
3. 单账号搭环境，确认出口和断网保护生效。
4. 跑稳一个月再考虑加号。
5. 记忆备份从第一天就做。
