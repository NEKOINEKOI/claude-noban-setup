# 02 — 准备工作

需要准备四样东西。缺哪样先补哪样。

## 1. 一台美区亚马逊云服务器（AWS EC2）

- 区域选美国（作者建议西部，如 us-west；美东 us-east-1 更便宜，价格数据多基于美东）。
- 起步配置 t3.small（2 vCPU / 2 GiB）够用；t3.micro（1 GiB）更便宜但跑远程桌面 + Chrome 会紧。
- 新账号有抵扣额度（AWS 现行政策：$100 起，完成引导任务可到 $200，抵扣 6 个月），但注意不是过去那种"免费一年"。

## 2. 一个美国静态住宅 IP

- **关键区分**：要的是"住宅代理的固定出口"，**不是** AWS 控制台里的静态公网 IP。后者是机房 IP，正是要躲的。
- 尽量和服务器在同一地理区域（比如都在美国西部），先把链路跑稳。
- 优先选**独享**静态住宅 IP，共享 IP 会被别人的操作连累。
- 拿到后自己验证：IP 查询工具看归属地是不是美国、运营商是不是当地宽带运营商（如 AT&T / Comcast），而不是机房 ASN。

### 选购避坑

| 坑 | 说明 |
|---|---|
| 买到被封过的 IP | 风险提示：如果买到之前已被封号的 IP，新账号会被连坐封号。这是买住宅 IP 最大的运气成分。 |
| "住宅 IP"其实是机房 IP | 价格明显低于市场区间的多半有问题。拿到手必须自己验证归属。 |
| 共享当独享卖 | 独享 $3–10/月是正常区间，$1 上下的多半是共享。 |
| 不先测试就包月 | 靠谱商家支持试用或短买，先用目标平台实测能不能正常用、延迟如何，再包月。 |
| 流量/并发限制没问清 | 看起来便宜的套餐算上流量费可能更贵。问清流量上限和并发数。 |

参考价：独享静态住宅 IP 约 **$3–10/月**（指定城市或运营商会上浮 20%–50%）。详见 [`07-成本估算.md`](07-成本估算.md)。

## 3. 一个能用的 Codex

- 作用：通过 SSH 帮你搭环境、检查代理、验证断网保护。
- 你负责说清要求（有现成模板：`prompts/codex-setup-prompt.md`），它负责落实配置。
- 复用已有订阅则边际成本为 0。

## 4. Claude Pro 账号

- 原文建议买**已完成 KYC 验证的成品号**，因为现在充值 Pro 也必须完成 KYC。
- ⚠️ 风险如实提示：成品号违反服务条款、可能被找回、来源不明。这是灰产环节，自行评估合规风险。
- 起步策略：**先一个账号**，观察一个月；有实际需要再加号；稳定后再考虑 Max。用满一个月也不代表后续绝对安全。
- 账号不够用多个 Pro，不必急开 Max——记忆可以共享，换号不麻烦。

## 开局顺序建议

1. 先买一个住宅 IP，短买测试纯净度和归属。
2. 确认 IP 干净后开 AWS 服务器，同一区域。
3. 单账号搭环境，验证出口和断网保护完全生效。
4. 跑稳一个月，再考虑加第二个账号。
5. 无论几个号，记忆备份 GitHub 这一步从第一天就做。
