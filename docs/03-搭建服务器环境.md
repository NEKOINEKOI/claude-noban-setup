# 03 — 搭建服务器环境（第一步）

目标：服务器上所有业务联网都走固定住宅出口；代理挂了就断网，不回退。

## 交给 Codex 的指令

把下面整段发给 Codex，通过 SSH 连上服务器后落实。可直接复制 `prompts/codex-setup-prompt.md`。

> 帮我搭建一个固定出口的 Claude 使用环境。服务器上所有业务联网，包括 Claude Code、浏览器和后台程序，都必须走指定的静态住宅 IP。住宅代理断开、超时或者重启时，宁可断网，也不能切回服务器原始 IP。保留必要的 SSH 管理通道，并验证保护规则在服务器重启后仍然有效。

这一步的命门：宁可断网，也绝不换出口。

## 配置完成校验清单（逐条核对，缺一不可）

- [ ] Claude Code、浏览器及后台程序统一走住宅代理，不退回原始 IP。
- [ ] 代理断开、超时或重启时，业务断网，不是回退。
- [ ] DNS 已接管，IPv6 和其他 UDP 直连已阻断。
- [ ] 多次整机重启后保护策略依旧生效，SSH 管理通道保留。
- [ ] 断开代理做一次验证：确认业务真的断了，而不是悄悄切回原始 IP。

校验不过就不要进下一步。

## 配置完成后

1. 打开远程桌面，在服务器内置浏览器登录 Claude。
2. 账号还没登录时，不要做实际对话测试。
3. 后续重连用启动脚本，不要手动临时改网络设置——那样会绕过保护规则。

## 常见失败信号

| 现象 | 判断 |
|---|---|
| 代理断了 Claude 还能用 | 配置失败，流量切回了原始 IP，重做 |
| 浏览器显示机房 ASN | 住宅代理没接管，或买到了假住宅 IP |
| 重启后保护失效 | 规则没写进开机自启，要求修正 |
| SSH 也断了 | 管理通道没保留，要求单独放行 SSH |
