# 04 — 登录与授权（第二步）

目标：登录这个动作本身也在服务器里完成，不让任何登录请求从本地发出。

## 装远程桌面和 Chrome

让 Codex 给服务器安装远程桌面和 Chrome，通过 SSH 隧道连远程桌面。连上后等同于操作另一台电脑。

## 在服务器里完成登录

1. 打开服务器内的 Chrome，完成 Claude 登录以及 Claude Code 授权。
2. 关联使用的邮箱也在服务器浏览器内登录。收邮件、点登录链接都在这个环境完成。

原因：邮件里的图片、链接会产生网络请求；登录链接点开后，请求由当前打开的浏览器发出。邮箱在本地登，请求就从本地真实环境发出，前面搬服务器的工作就白费了。

## 多账号：Cookie 隔离

登录多个账号，每个号一个独立的 Chrome 用户配置文件：A 号一套，B 号一套，让 Codex 生成对应的桌面快捷方式，避免 Cookie 和会话混淆。

说明：这一步只隔离登录状态 Cookie，不为不同账号分配独立出口。所有账号仍共用同一台服务器和同一个住宅 IP。

## 检查点

- [ ] Claude 登录和 Claude Code 授权都在服务器浏览器完成。
- [ ] 邮箱在服务器浏览器登录，登录链接在服务器环境点开。
- [ ] 多账号各有独立 Chrome 用户配置和桌面快捷方式。
- [ ] 本地浏览器没有留下任何 Claude 登录请求。
