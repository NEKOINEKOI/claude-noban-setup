# 06 — 记忆备份到 GitHub（非常重要）

> 这是整套方案里唯一没有副作用、纯赚的一条。就算不做前面的服务器方案，也建议单独做。

## 作用

让 Claude 协助实现记忆上传 GitHub，提供 GitHub 凭据即可，并设置定时更新上传记忆备份。

- 就算账号被封禁，记忆数据保存在 GitHub，可以无缝迁移到其他 Claude 账号。
- 即使这套服务器方案后续出现封号，记忆数据也能留存。

## 备份目录一般包含

- `memory`
- `readable`
- `sessions`
- `tools`
- 工作空间代码
- 各类交接脚本与文档

## 给 agent 的指令示例

> 帮我把当前环境的 memory、readable、sessions、tools、工作空间代码和交接脚本，定时备份到我的 GitHub 私有仓库。写一个可重复执行的脚本，并设置定时任务每天运行。备份前确认目标仓库是私有的，避免敏感信息泄露。

## 检查点

- [ ] 目标 GitHub 仓库是**私有**的（记忆里可能有敏感信息）。
- [ ] 备份脚本可重复执行，不会重复堆积旧文件。
- [ ] 定时任务已设置，并测试过一次手动运行成功。
- [ ] 恢复路径验证过：能从 GitHub 把记忆拉回来用。

⚠️ 提醒：GitHub 凭据不要明文写进脚本或提交进仓库，用环境变量或凭据管理工具。
