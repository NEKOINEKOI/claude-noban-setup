# 06 — 记忆备份到 GitHub

号万一被封，会话和记忆可能一起没。把 memory、readable、sessions、tools、项目代码、交接脚本定时备份到 GitHub，号没了记忆还在，能迁到新号。这一步没有副作用，单独做也值。

## 备份内容

- memory
- readable
- sessions
- tools
- 工作空间代码
- 各类交接脚本与文档

## 给 agent 的指令

> 帮我把当前环境的 memory、readable、sessions、tools、工作空间代码和交接脚本，定时备份到我的 GitHub 私有仓库。写一个可重复执行的脚本，设置每天运行。先确认目标仓库是私有的。

## 检查点

- [ ] 目标是私有仓库，记忆里可能有敏感信息。
- [ ] 脚本可重复执行，不堆积旧文件。
- [ ] 定时任务已设置，手动跑过一次成功。
- [ ] 验证过恢复：能从 GitHub 把记忆拉回来用。

GitHub 凭据用环境变量或凭据管理工具，不要明文写进脚本或提交进仓库。
