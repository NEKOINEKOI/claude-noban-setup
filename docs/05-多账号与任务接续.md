# 05 — 多账号与任务接续

有多个账号时才做这一步。

## 用 tmux 做切换入口

让 Codex 配好命令别名：输入 `claude-a` 进 A 号环境，输入 `claude-b` 进 B 号环境。

## 要区分的两件事

1. 账号登录凭证互相独立保存。
2. 项目资料和工作记忆共享——多个环境共用同一份项目代码、CLAUDE.md、任务进度、交接记录。

## 任务怎么接续

A 号把完成进度、代码改动、下一步计划写进共享交接文件；切到 B 号后，读交接文件接着干。

```text
tmux 维持终端会话  +  共享交接文件负责交接
```

两条限制：

- 不会自动合并各账号的完整聊天历史，能接续的是进度和交接记录。
- 禁止多个会话同时改同一份代码。

## 账号数量的边界

单台服务器 + 同一个静态住宅 IP，挂 3 个 Pro 账号可以跑。账号上限没有验证过，3 个能跑不代表更多也安全。

建议流程：先单账号把环境搭好，确认出口和断网保护生效，再考虑加号。
