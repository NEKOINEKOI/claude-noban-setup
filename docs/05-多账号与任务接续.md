# 05 — 多账号与任务接续

> 只有主人有多个账号时才做这一步。单账号可跳过。

## 用 tmux 做切换入口

搭配 tmux 搭建账号切换入口，例如：

- 输入 `claude-a` 进入 A 账号环境；
- 输入 `claude-b` 进入 B 账号环境。

让 Codex 配好这些命令别名。

## 要区分的两件事

1. **账号登录凭证互相独立保存**——每个账号的 Cookie / 会话各归各。
2. **项目资料、工作记忆做共享**——多个环境共用同一份项目代码、CLAUDE.md、任务进度、交接记录。

## 任务怎么接续

- A 账号完成进度、代码修改内容、下一步计划，全部写入**共享交接文件**。
- 切换到 B 账号之后，读取交接记录继续开展工作。

```text
tmux 负责维持终端会话  +  共享交接文件负责任务交接
```

## 两条例外规则

- **不会自动合并各个账号的完整聊天历史**——能接续的是"进度和交接记录"，不是完整对话。
- **禁止多个会话同时修改同一份代码**——交接文件是串行读写的，同时改会冲突。

## 实测边界

单台服务器、同一个静态住宅 IP，稳定运行 3 个 Pro 账号。**没有测试账号上限**；3 个账号稳定，不代表更多账号就一定安全。

建议流程：先用单个账号搭环境，确认网络出口和断网保护完全生效，再考虑增加账号投入。
